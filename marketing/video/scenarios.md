# Банк видеосценариев

Сценарии для Reels / Shorts / TikTok. Кадры экрана снимаются автоматически (см. раздел ниже), демо-данные ставятся так:

```bash
npm run seed:demo
```

Два готовых соревнования после сида:
- **Спартакиада школ Астаны 2026** — 16 команд, 4 группы, сыгранная группа + плей-офф до финала, составы, бомбардиры.
- **Корпоративная лига Астаны 2026** — 10 команд, сыграно 6 туров из 9: видна и таблица, и ближайшие матчи.

Названия школ, компаний и игроков вымышленные — это витрина продукта, а не отчёт о реальных соревнованиях. Если снимаете кадр крупным планом, где название читается, это стоит один раз проговорить в закреплённом комментарии.

## Как устроен сценарий

Каждый сценарий — это:

| Поле | Что это |
|---|---|
| **Хук** | Первые 1,5–2 секунды. Решают, досмотрят или пролистают. Произносится и дублируется текстом на экране. |
| **Кадры** | Что именно показывать по секундам. «Экран» = запись экрана, «Лицо» = вы в кадре. |
| **Голос** | Что говорите. Пишется разговорно, не читается с листа. |
| **Титры** | Текст поверх кадра. Всегда — половина смотрит без звука. |
| **CTA** | Один и только один призыв в конце. |

Общие правила:
- 20–45 секунд. Длиннее — только для YouTube.
- Лицо в первом кадре, экран — начиная со второго. Лицо в кадре поднимает досматриваемость, экран без лица выглядит как реклама.
- Ни одного кадра без титра. Титр держится минимум 1,2 секунды.
- Вертикаль 1080×1920. Запись экрана делается в окне браузера, суженном до вертикали, а не кропом широкого кадра.

Обложка Reels собирается студией: положите слайд с `"size": "story"` в `marketing/studio/posts/` и запустите `node marketing/studio/render.mjs`.

## Экран снимать не нужно — он уже снят

```bash
node marketing/studio/capture.mjs
```

Скрипт сам заходит в приложение и записывает шесть клипов в `marketing/footage/`. Смотреть и скачивать их удобнее в платформе: `/admin/content`, вкладка «Видео».

| Клип | Что на нём | Куда идёт |
|---|---|---|
| `01-public-phone` | публичная страница на телефоне, вертикаль | основной кадр Reels и TikTok, кропить не нужно |
| `02-tabs-walkthrough` | обход всех разделов соревнования | клип-донор: режется на куски по 2–3 секунды |
| `03-bracket` | сетка плей-офф | финал ролика перед призывом |
| `04-championship` | страница чемпионата | сценарии про сезоны и историю |
| `05-corporate` | корпоративная лига после 6 туров | сценарии на HR |
| `06-wizard` | мастер создания | открывающий кадр про оцифровку |

### Как из этого собирается ролик

1. Берёте хук из сценария выше.
2. Снимаете на телефон 15–30 секунд себя, произнося текст. Один дубль — один ролик.
3. В CapCut: ваша дорожка первой, поверх — куски из `footage/` по таймингу из колонки «Кадры».
4. Титры из колонки «Титр». Субтитры автоматом, казахский правите руками.

Единственное, что снимаете вы, — себя. Всё остальное уже лежит готовым.

Если интерфейс изменится — перезапустите `capture.mjs`, клипы перезапишутся.

## Правила, которые не нарушаем

- **Никаких эмодзи** — ни в титрах, ни в подписях, ни в обложках. Вместо них — иконка, цветной блок или номер.
- **Никакого слова «Live»** и производных в титрах и подписях. Пишем «Табло», «Счёт в реальном времени». Причина — в `CLAUDE_CONTEXT.md`: связка «live + спорт + счёт» читается антифрод-сканерами платёжных провайдеров как профиль ставок, и один отказ мы уже получили.
- **Никаких обещаний, которых нет в продукте.** Если фича на бесплатном плане недоступна — говорим об этом в том же ролике, а не в комментариях.
